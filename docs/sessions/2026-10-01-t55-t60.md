## 4. Gotchas & Lessons Learned

1. **`ensureMetricsPersistence` MUST run AFTER `metricsService = NewMetricsService()`** — earlier wiring silently no-ops (bug shipped in `7c0cc93`, fixed in `f083711`)
2. **Hetzner MainConfigDir is WD-relative** — persist files land in `/opt/tormentnexus/.hypernexus/`, not `/root/.hypernexus/`
3. **`actions/setup-go@v6` + old `go-version` = instant fail** — `GOTOOLCHAIN=local` won't auto-download
4. **`actions/setup-node@v5` needs `package-manager-cache: false`** when job only uses `npm ci`
5. **Same byte size ≠ same binary** — always compare `sha256sum` after small patches
6. **`strings | grep` is useless on `-s -w` binaries** — use `sha256sum` + behavioral smoke
7. **Windows has no `gzip` on PATH** — use .NET `GzipStream` for compression
8. **PowerShell expands `$(date +%s)` inside ssh remote strings** — ship a `.sh` file
9. **PowerShell here-strings corrupt TypeScript template literals** — use write tools for TS/JSX
10. **Write tool corrupts JSX template literals** — use string concatenation `'$' + value` instead of `` `$${value}` `` in JSX
11. **`fmt.Sprint(m["key"])` on missing map keys emits `<nil>`** — use `optionalString`
12. **Dashboard overlay must exclude `node_modules` but INCLUDE `.next-build`** — `distDir` is `.next-build` and required at runtime
13. **Never ship pnpm `node_modules` via Windows `tar -czf`** — drops symlinks → `Cannot find module 'next'`
14. **`TestCouncilVisualBridgeRoutes` hangs when tRPC upstream is down** — use `-run` filters
15. **`PPID` is readonly in bash** — use `PARENT` for process parent PID
16. **Bash `gzip: No such file` after first decompress** — check if file already decompressed before re-running
17. **HANDOFF.md working copy can be clobbered by concurrent processes** — `git checkout -- HANDOFF.md` to restore, then edit

## 5. Architecture Patterns

### HTTP Fallback Pattern (dashboard resilience)
```typescript
// use-startup-status.ts — tRPC primary, kernel HTTP fallback
const query = trpc.startupStatus.useQuery(undefined, { retry: false });
const [fallback, setFallback] = useState(null);
useEffect(() => {
  if (query.data) return;
  // poll kernel HTTP when tRPC is down
  const load = async () => setFallback(await fetchKernelJSON('/api/startup/status'));
  load();
  const id = setInterval(load, refetchIntervalMs);
  return () => clearInterval(id);
}, [query.data]);
return { data: query.data ?? fallback, source: query.data ? 'trpc' : 'kernel-http' };
```

### Metrics Local Fallback Pattern
- `metrics.MetricsService` is the local event store
- Handlers fall back to it when upstream tRPC is down — return **200 + `fallback: go-local-metrics`**, not 503
- `localMetrics()` helper picks `s.metricsService` else `GetMetricsService()`

### Provider Breakdown Aggregation
- Aggregates from the existing routing ring (no second ledger)
- `ProviderBreakdown()` returns `ProviderUsage` per provider
- Tokens/cost computed from `RoutingEvent.tokenInput/tokenOutput` × price table

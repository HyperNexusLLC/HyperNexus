# HyperNexus Demo Script (60-90 seconds)

## Setup

- Terminal window open (clean, dark theme)
- Claude Code, Cursor, or any MCP-compatible AI tool ready
- Browser on hypernexus.site

## Scene 1: Install & Start (10 seconds)

```bash
# Terminal
curl -sSL tormentnexus.site/install.sh | sh
tormentnexus daemon start
```

**Voiceover:** "Install TormentNexus in one command. Start the daemon."

## Scene 2: Connect to AI Tool (15 seconds)

```bash
# Show the MCP config
cat ~/.cursor/mcp.json
```

**Voiceover:** "Add the MCP config to any AI tool — Cursor, Claude Code, Copilot, Aider. One config, universal parity."

## Scene 3: Cross-Tool Memory (20 seconds)

```
# In Cursor/Claude Code, ask:
"What files did I work on yesterday?"
```

**Voiceover:** "Ask your AI about previous work. TormentNexus remembers context across sessions and across tools. Claude Code can see what Cursor learned."

## Scene 4: Progressive Tool Routing (15 seconds)

```
# Show terminal output or dashboard
"Notice only 3 tools injected instead of 50. Context usage: 600 tokens instead of 50,000."
```

**Voiceover:** "Progressive tool routing injects only the relevant tools per request. 95% context reduction."

## Scene 5: Call to Action (5 seconds)

```
# Browser: hypernexus.site
```

**Voiceover:** "Try it free at tormentnexus.site. Link in bio."

---

## Recording Tips

- Use OBS or QuickTime screen recording
- Keep terminal clean (no extra tabs)
- Use a monospace font (Fira Code, JetBrains Mono)
- Background music: subtle lo-fi or ambient (low volume)
- Total length: 60-90 seconds max

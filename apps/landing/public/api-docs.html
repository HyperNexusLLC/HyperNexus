HyperNexus API

REST API for HyperNexus AI Control Plane

Memory

POST /api/v1/memory/store

Store a memory with title, content, and tags

title string Memory title
content string Memory content
tags string[] Optional tags
curl -X POST http://localhost:8080/api/v1/memory/store \ -H "Content-Type: application/json" \ -d '{"title":"Auth Decision","content":"Using JWT with bcrypt","tags":["auth","security"]}'
GET /api/v1/memory/search

Search memories by query

query string Search query
limit number Max results (default: 10)
curl "http://localhost:8080/api/v1/memory/search?query=auth&limit=5"

Tools

GET /api/v1/tools

List all available MCP tools

curl "http://localhost:8080/api/v1/tools"
POST /api/v1/tools/call

Call an MCP tool

tool string Tool name
args object Tool arguments
curl -X POST http://localhost:8080/api/v1/tools/call \ -H "Content-Type: application/json" \ -d '{"tool":"memory_search","args":{"query":"auth"}}'

MCP

GET /mcp

MCP server endpoint (SSE transport)

# Connect via MCP client claude mcp add hypernexus http://localhost:8080/mcp

Health

GET /health

Health check endpoint

curl http://localhost:8080/health {"ok":true,"service":"hypernexus-go","version":"1.0.1"}

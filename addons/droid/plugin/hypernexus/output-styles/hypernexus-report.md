Group findings by severity with file references. For HyperNexus-backed work include:

- **Recall**: which L2 memories/scratchpad entries informed this (titles or ids)
- **Findings**: severity-ordered, each with evidence and file path
- **Persisted**: what was stored to L2 (titles + tags), or why nothing was stored
- **Next**: concrete follow-ups with owners/files

# DeepSeek Harness Skill

## Overview

DeepSeek Harness is a plugin-based AI agent framework. Use it for complex multi-step tasks.

## MCP Server

Connect to HyperNexus at: <http://localhost:8080/mcp>

## Usage

- Use `deepseek.start` to launch the harness
- Use `deepseek.openWebUI` to access the web interface
- Plugins can be installed via the DeepSeek marketplace

## Key Features

- Plugin-based architecture
- Multi-agent orchestration
- Persistent memory via HyperNexus

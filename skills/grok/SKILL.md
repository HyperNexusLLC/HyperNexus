# Grok Skill

## Overview

Grok is xAI's AI model. Use it for code explanation, chat, and analysis.

## MCP Server

Connect to HyperNexus at: <http://localhost:8080/mcp>

## Usage

- Use `grok.chat` to open a chat panel
- Use `grok.explain` to explain selected code
- Configure API key in settings

## Key Features

- Code explanation
- Natural language chat
- Integration with HyperNexus memory
